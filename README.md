# 간 초음파 3D 아틀라스

표준 간·상복부 초음파 17개 영상을 세 가지로 함께 보여 주는 교육용 웹페이지입니다.

- 프로브가 몸 표면으로 이동하는 애니메이션
- three.js 3D 해부 모델(Couinaud 분절 S1–S8, 문맥·간정맥·하대정맥·동맥, 담낭·담관, 췌장, 비장, 신장, 소화관, 늑골)과 그 위의 스캔 단면
- 같은 단면으로 합성한 B-mode 초음파 영상과 구조물 라벨

## 여는 법

`index.html`을 더블클릭해 엽니다(인터넷 연결 필요: three.js와 글꼴을 CDN에서 불러옵니다).
브라우저가 로컬 파일 접근을 막으면 `serve.bat`을 실행하세요. 로컬 서버(포트 8917)가 켜지고 브라우저에서 `http://localhost:8917/`가 열립니다.

## 호흡과 자세

호흡이나 자세를 바꾸면 라벨 볼륨과 3D 메시를 함께 변형합니다. 그래서 B-mode 영상, 3D 모델, 단면 색, 프로브가 피부에 닿는 위치, 늑간 창 찾기가 모두 바뀐 위치를 씁니다.

- 모델 원래 상태를 평상 호흡(앙와위)으로 봅니다.
- 흉벽(늑골·늑연골·피부·지방·근육)
  - 흡기: 늑골 앞끝이 최대 1.2 cm 올라가고 0.8 cm 앞으로 나옵니다(펌프 손잡이 운동). 아래쪽 늑골은 바깥으로 3.5% 벌어집니다(양동이 손잡이 운동). 늑골연 아래 복벽은 1 cm 앞으로 나옵니다. 흉벽과 복벽의 경계는 높이가 아니라 늑골·늑연골이 실제로 있는 곳을 따릅니다.
  - 강제 호기: 같은 운동이 반대 방향으로 절반만 일어납니다.
- 흉강·복강 장기
  - 횡격막 돔은 최대 흡기에서 3.5 cm 내려가고 최대 호기에서 2.5 cm 올라갑니다. 깊은 호흡 때 횡격막 이동 범위는 약 6 cm입니다(정상 57–70 mm, Boussuges 외, Chest 2009).
  - 각 장기는 돔 이동의 일정 비율만큼 움직입니다: 간·담낭·간내 혈관 1, 주문맥 0.85, 비장 0.85, 위 0.75, 신장 약 0.6, 췌장 0.55, 대장 0.25–0.7, 대동맥 0.
  - 폐 아랫부분은 횡격막을 따라 내려가 늑골횡격막각을 채웁니다. 그래서 깊은 흡기 때 늑간 창의 머리 쪽이 폐에 가려집니다.
  - 이 목표 이동량을 부드러운 변위장으로 이어 붙이므로 장기 사이를 지나는 혈관도 끊기지 않습니다. 흉벽·복벽과 장기 사이는 미끄러집니다(흉막·복막). 척추·요근·대동맥은 고정입니다.
- 측와위
  - 위쪽(침대 반대쪽) 횡격막은 1 cm 내려가고 아래쪽은 1 cm 올라갑니다.
  - 장기는 중력 쪽으로 쏠립니다. 좌측와위 기준으로 간 1.2 cm, 담낭 2 cm, 대장 2 cm, 위 1.4 cm, 우신 1 cm입니다. 우측와위에서는 비장 1 cm, 좌신 0.8 cm, 대장 2 cm, 위 1.4 cm입니다.
  - 위쪽 흉벽의 늑간이 10% 넓어지고, 아래쪽 흉벽은 3% 좁아집니다.
  - 위 가스는 위로 올라갑니다. 좌측와위에서는 전정부·십이지장 구부, 우측와위에서는 위저부에 모입니다('위 내용'이 가스일 때).
- 프로브
  - 기본값: 같은 구조를 다시 겨냥합니다. 목표점은 장기와 함께, 피부 접촉점은 흉벽과 함께 움직입니다.
  - `프로브 고정`을 켜면 원래 자리와 빔 방향을 유지하고 장기만 움직입니다.

## 실제 초음파 영상 넣기

`us_images/01.jpg` ~ `us_images/17.jpg`(또는 `.png`)를 넣으면 해당 영상 화면의 "실제 초음파 영상" 칸에 자동으로 나타납니다.
그 칸에 이미지 파일을 끌어다 놓아도 되며, 이 경우 그 브라우저에만 저장됩니다.

## 파일

```
index.html          앱 본체 (3D, 초음파 합성, UI)
views.js            17개 표준영상 정의: 프로브 위치·빔 방향·화면 방향, 검사 방법, 확인할 것
data/anatomy.js     압축된 메시 43개 + 1.5 mm 라벨 볼륨 (BodyParts3D 파생 데이터)
tools/              데이터 재생성 스크립트
serve.bat           로컬 서버 실행
```

영상 위치를 고치려면 `views.js`만 수정합니다. 각 영상은 다음 값으로 정의합니다.
`T`는 중심 빔이 지나는 점, `E`는 피부 접촉 근사점이고 `E`가 없으면 `D`(빔 방향)를 씁니다. `H`는 화면 왼쪽에 올 방향입니다. 좌표는 BodyParts3D mm(+x 환자 좌측, +y 등쪽, +z 머리쪽)입니다.

## 데이터 다시 만들기

Python 3.11, `numpy scipy trimesh fast-simplification scikit-image`가 필요합니다. 작업 폴더에 `groups.json`을 복사한 뒤 차례로 실행합니다.

```bash
python tools/fetch_index.py      # BodyParts3D isa zip 목차만 HTTP Range로 읽기 (zip_index.json)
python tools/fetch_objs.py       # groups.json에 적힌 OBJ만 받아 obj/ 에 저장 (~15 MB)
python tools/build_volume.py obj .
python tools/build_assets.py . data/anatomy.js
python tools/portal_segments.py data/anatomy.js   # 구역은 간정맥·열, 분절은 문맥 영역으로 다시 나눔
python tools/anatomy_fixes.py data/anatomy.js anatomy.stage1.js   # 해부 보정(2026-10 감사): 간동맥(HA)·위십이지장동맥(GDA)·좌간관(LHD) 라벨, 총담관·비정맥 경로, 늑골연 아래 횡격막 띠, 간–우신 접촉
python tools/portal_segments.py anatomy.stage1.js data/anatomy.js data/anatomy.js   # 분절 재계산, 셋째 인자와 달라진 분절 메시 재생성
```

## 출처와 한계

- 3D 해부: BodyParts3D, © The Database Center for Life Science, CC BY-SA 2.1 JP. `data/anatomy.js`도 같은 라이선스를 따릅니다.
- Couinaud 분절: 원본 분절 메시는 라벨이 실제 위치와 어긋나 있어 `tools/portal_segments.py`로 다시 계산했습니다. Couinaud처럼 구역(sector)은 간정맥이 지나는 면으로, 분절은 문맥 분지가 맡는 영역으로 나눴고, 이름은 Brisbane 2000 용어를 따릅니다.
  - 좌우 간(Cantlie 선): 담낭와에서 합류부 직전의 중간간정맥 본간까지 잇는 면입니다.
  - 우전(S5·S8)·우후(S6·S7) 구역: 높이마다 우간정맥이 지나는 면입니다. S7·S8 문맥 분지 옆을 따라가는 지류는 빼고, 면이 전·후 문맥 분지 사이를 벗어나지 않게 했습니다. 우간정맥이 끝난 위아래 높이에서는 끝의 각도를 그대로 이어 씁니다. 면은 우간정맥 본간(굵기 2 mm 이상)에서 5° 이상 벗어나지 않게 했습니다.
  - S2·S3: 좌외측구역 안에서 가장 가까운 P2·P3 문맥 가지의 영역으로 나눕니다(Brisbane 2000). 좌간정맥은 대략적인 경계이며 대부분 S2 쪽 경계 부근을 지납니다.
  - S3·S4: 좌문맥 제대부를 지나는 제대열(겸상인대·원인대 선)로, 하대정맥 바로 앞에서 약간 왼쪽에 놓입니다.
  - S5/S8, S6/S7, S4a/S4b: 구역 안에서 가장 가까운 분절 문맥 가지의 영역입니다(S6/S7은 머리–꼬리 방향 거리에 2배 가중치). 분지 위치는 스크립트의 `SEEDS`에 있습니다.
  - 문맥 이름은 공급하는 쪽으로 붙였습니다(S5–S8은 우문맥, S2–S4는 좌문맥). 우문맥은 다시 전분지(RAPV, S5·S8)와 후분지(RPPV, S6·S7)로 나누고, 둘로 갈라지기 전의 짧은 본간만 RPV로 남깁니다.
  - S1: 원본 미상엽 메시를 사용했습니다.
  - 한계: 이 모델의 문맥 트리는 몇 단계에서 끝나므로 분절 경계는 실제 문맥 영역의 근사입니다. 모델의 혈관 배치 때문에 S5 분지의 일부는 담낭와 높이에서 S4b 쪽에 걸립니다. 좌외측구역을 문맥 영역으로 나누므로 좌간정맥 일부는 S2 안에 놓입니다. S8 앞쪽 가지 하나는 복셀에서 좌문맥과 맞닿아 있어 골격 트리상 좌문맥에 붙으므로, S4a 안을 지나는 그 줄기는 좌문맥으로 이름 붙이고 S8 분지점은 Cantlie 면 바로 오른쪽에 둡니다. 평면 기준 분절과 실제 문맥 영역이 넓게 어긋날 수 있다는 점도 알려져 있습니다(Fasel 외 1998). 실제 환자의 변이와 다를 수 있습니다.
  - 참고: Couinaud C. *Le Foie: études anatomiques et chirurgicales*. Masson, 1957 · Bismuth H. World J Surg 1982;6:3–9 · Strasberg SM 외. The Brisbane 2000 Terminology of Liver Anatomy and Resections. HPB 2000;2:333–339 · Soler L 외. Comput Aided Surg 2001;6:131–142 · Selle D 외. IEEE Trans Med Imaging 2002;21:1344–1357 · Fasel JH 외. Radiology 1998;206:151–156.
- 초음파 영상: 조직별 에코, 감쇠, 경계면 반사(간정맥 벽은 빔이 수직일 때만 밝음), 스펙클, 뼈 음영, 장 가스의 밝은 경계와 지저분한 음영·잔향, 후방 증강, 횡격막 거울상, 폐의 링다운과 A선을 단순 규칙으로 흉내 낸 시뮬레이션입니다. 위는 공복 상태를 기본으로 하고 영상 아래 '위 내용'에서 가스·물 상태로 바꿀 수 있습니다. 10번은 탐촉자로 눌러 대장 가스를 밀어낸 상태(`compressBowel`)로 그립니다.
- 늑간·옆구리 영상(8–10번)의 프로브 위치: 이 모델의 늑골·늑연골 배치에서는 교과서 위치(전액와선의 7·8번째 늑간, 9번은 전·중액와선 사이)에서 우문맥 전분지의 고래꼬리나 우간정맥 장축을 늑골 음영 없이 교과서 배치대로 얻을 수 없었습니다. 그래서 8번은 제7늑연골 위, 9번은 그보다 약간 뒤·한 칸 아래인 전액와선 부근 늑골연 바로 위에 프로브를 두었습니다(교과서보다 앞쪽). 10번은 간 S6을 우신 상부 앞바깥면까지 넓혀 화면 가운데(깊이 7–10 cm)에서 S6이 우신 위쪽 끝에 맞닿지만(간–신 경계), 중앙 빔과 그보다 화면 오른쪽(꼬리 쪽)에서는 간만곡부 대장이 여전히 간 S6과 우신 사이에 끼어 있어 교과서처럼 간–신 경계가 길게 이어지는 Morison 와는 보이지 않습니다. 간 S6 하단도 우신 하극보다 높은 곳에서 끝나고, 단면은 관상면에서 약 45° 기울어 있습니다.
- 모델 위치: 이 모델(BodyParts3D)은 간·담낭이 늑골연보다 4.5–6 cm 낮게 놓여 있어, 늑골하 주사의 프로브가 교재보다 아래에 그려지고 담낭 장축이 앞뒤로 서 있으며(장축 주사는 빔을 꼬리 쪽으로 기울여 맞춤) 간 좌엽이 췌장 앞까지 내려오지 않습니다(깊은 흡기로 바꾸면 내려옵니다). 이 상태를 평상 호흡으로 두었으므로 '최대 호기'에서도 간 하연은 교재보다 낮습니다. 비장은 길이·용적은 정상이지만 두께가 상한에 가깝습니다.
- 호흡·자세 변형의 한계: 장기는 이동만 하고 모양은 거의 그대로입니다. 흡기 때 간정맥·하대정맥 구경 변화, 측와위에서 간의 회전, 아래쪽 흉벽이 침대에 눌리는 것, 대장 가스의 재분포는 넣지 않았습니다. 이동량은 문헌 범위 안에서 고른 대표값이며 사람마다 다릅니다.
- 표준영상 구성: 복부초음파 강의 시리즈(Vol.01–19) 교재의 "복부초음파 기본 17 VIEW"(교재 p.42) 순서와 이름을 따랐습니다(1–14 앙와위, 15–17 좌측와위). 참고 자료는 대한초음파의학회 상복부 초음파 표준영상(일반 12·정밀 15)과 국립암센터 간암 검진 질지침입니다.
